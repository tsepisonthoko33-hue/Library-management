# Community Library Management System

## Run the project
1. Install Node.js.
 
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local address printed by Vite.

## Demo login
- Membership ID: `ADMIN001`

## Features
- Dashboard with book counts and low-stock warnings.
- Add, update and delete books.
- Add stock and record borrowed copies.
- Transaction history.
- Login and user management for Admin.
- React Router navigation.
- Local Storage persistence.
